# Keystrip

Keystrip is a native SwiftUI app for macOS, iPadOS, and iOS that edits the
`.dsi` label databases used by the DESI Labeling System to print key labels
for Allworx desk phones (9212 and 9224). Edit on your Mac or iPad, then print
from the Windows DESI app as usual.

Keystrip is not affiliated with DESI Telephone Labels, Inc. or Allworx.
